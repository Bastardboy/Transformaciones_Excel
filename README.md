# 🚀 Desarrollo de transformación de datos y descarga masiva.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

## 📌 Descripción

Se desarollan técnicas de transformación de datos en archivos excels. El principal objetivo, automatizar este proceso debido a fallas que pueden tener los archivos tras ser enviados al área de postventas, además de permitir la descarga.
En segundo caso, está la descarga masiva de facturas, la cual previamente era desarrollada manualmente modificando parámetros de una url. Actualmente pueden ser descargadas ingresando varios números de folio, y con caracterísitcas claves. Por obvias razones, no se presenta el enlace pertinente en el código.

## 🛠️ Tecnologías Utilizadas

- **Python** - Lenguaje de programación principal
- **Flask** - Framework para sitios web rápidos y optimizados
- **Pandas** - Librería usada para la manipulación de datos en las transformaciones
- **PyPDF2** - Encargado de poder fusionar varios PDF a la hora de descarga.
- **Huawei Cloud** - Despliegue de la aplicación

## 🎨 Características

- ✔️ Interfaz minimalísta
- ✔️ Claridad en los procesos
- ✔️ Generación de sesiones
- ✔️ Limpieza de archivos automática (después de cierto tiempo)
